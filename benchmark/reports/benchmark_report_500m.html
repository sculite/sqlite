6. Summary / Key Findings

  • Best config: GPU pipelined, batch 5M, in-memory → ~9.5s full-scan, up to 3.7x faster than CPU (E12: 37.19s → 9.50s).
  • Pipelining helps consistently: ~8-9% faster than non-pipelined GPU.
  • In-memory beats on-disk for GPU (~0.5-1s saved) but NOT for CPU (CPU is compute-bound, I/O already hidden).
  • Batch 5M-10M optimal; bigger batches are worse or OOM.
  • CPU in-memory doesn't improve because the 500M-row single-threaded scan is compute-bound.
  • 0-match queries (E1/E9) don't benefit from the aggregate shortcut (falls back), so pipelining shows no gain there.
  • Everything is correct across all configurations.
